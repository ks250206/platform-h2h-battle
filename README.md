# BRAMBLE

**Little paws. Heavy swords.** 小さな体に、大きな一撃。

## [ブラウザーでプレイ →](https://ks250206.github.io/platform-h2h-battle/)

インストール不要で、GitHub Pagesからそのままプレイできます。

ローポリの動物たちが大剣で戦う、斜め見下ろし視点の3Dプラットフォーム対戦アクションです。ため攻撃を見せて回避を誘い、キャンセルから次の手を選びます。蓄積した%が大きい相手ほど遠くへ吹っ飛び、落ちるたびに残機を1つ失います。最後まで残機を残したプレイヤーが勝利です。

現在はオフライン版です。1台のブラウザーで、キーボード（またはタッチ）の1人とゲームパッド最大4台が一緒に遊べます。乱闘は最大4人、一騎打ちと稽古は2人で、プレイヤーが入らない枠はCPUが担当します。一人用のCPUラダーと9課題の実戦チュートリアルも用意しました。オンライン対戦は未実装です。

## ローカルで起動

Node.js **26.13.1**、pnpm **12.21.0** を使用します。Nodeの指定は `.node-version`、pnpmの指定は `package.json` にあります。

```sh
pnpm install
pnpm dev
```

`pnpm install` は `pnpm-workspace.yaml` の `patchedDependencies` に登録した `patches/pixi.js@8.23.0.patch` を自動で適用します。MSAAのサンプル数を設定から指定できるようにするpixi.jsの修正などを含みます。

開発サーバーは `http://localhost:5176` で起動します。WebGL 2に対応したブラウザーで開いてください。BGMと効果音はボタンクリックやキー入力の初回操作後に有効になり、画面右上のボタンや設定ダイアログから音量とミュートを切り替えられます。

### ビルドとプレビュー

```sh
pnpm build
pnpm preview
```

プレビューは `http://localhost:4176` です。生成先は `dist/` で、相対パスを使った静的サイトとして配信できます。

## モード

| モード             | 内容                                                                                                                                                |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 一騎打ち / DUEL    | 1対1の対戦です。相手はCPUか2人目のプレイヤーを選べます。単発のほか、BO3（2勝先取）・BO5（3勝先取）のセット戦にも対応します。                        |
| 乱闘 / RUMBLE      | 4人戦です。全員が敵で、プレイヤーが入らない枠はCPUが戦います。                                                                                      |
| CPUラダー / LADDER | 全4戦勝ち抜きの一人用モードです。標準ルール（残機3）で4ステージ・4人のCPUに順に挑み、敗北・引き分け時は同じ相手から再挑戦できます。                 |
| 稽古 / PRACTICE    | ギミックのない足場で繰り返し練習できます。ダミーの行動、開始ダメージ、スタミナ無限、判定・状態表示、60Hzの入力記録と再生を使えます。2人対戦も可。   |
| 実戦チュートリアル | タイトル画面の下部ボタンから開く9つの独立課題です。移動・攻撃・回避・キャンセル・投げ・KO・場外復帰・移動セーフゾーン・受け身を実戦形式で学べます。 |

キャラクターはキツネのコハク、ウサギのシロ、クマのモカ、アライグマのスミの4種です。初期状態では枠の順にこの4人が並びますが、どの枠でも好きな動物・カラー・アクセサリを選べます（[キャラクターと見た目](#キャラクターと見た目)）。最初の枠は必ずプレイヤーが操作し、ほかの枠はプレイヤーかCPUを選べます。

## 対戦設定

タイトル画面の「対戦設定」ではステージ、ルール、試合形式、各枠のキャラクターと操作方法を選べます。選んだ内容（ステージ `stage`、ルールプリセットと各ギミック、制限時間 `time`、残機 `stocks`、試合形式 `setFormat`、CPUの強さ `difficulty` と個別上書き `overrides`、操作の割り当て `controls`、枠ごとの見た目 `loadouts`）はブラウザーの `localStorage`（キー `bramble.match.v1`）に保存され、次回も引き継がれます。項目が欠けた古い保存データは初期値で補完する仕組みです。

| 項目                   | 選択肢                                        | 初期値                             |
| ---------------------- | --------------------------------------------- | ---------------------------------- |
| ステージ               | 庭園 / 遺跡 / 回廊 / 工場                     | 庭園（浮遊庭園）                   |
| 試合形式（一騎打ち）   | 単発 / BO3（2勝先取） / BO5（3勝先取）        | 単発                               |
| ルールプリセット       | 標準 / 短時間 / ギミックなし                  | 標準                               |
| 制限時間               | 標準 / 短時間                                 | 標準                               |
| ギミック個別切替       | 足場崩落 / セーフゾーン / 爆撃 / 風           | すべてオン（ステージ非対応は固定） |
| 残機                   | 1〜5                                          | 3                                  |
| CPU の強さ             | よわい / ふつう / つよい                      | ふつう                             |
| キャラクター（枠ごと） | 動物4種 / カラー6色 / アクセサリ5種と「なし」 | 枠の順にコハク・シロ・モカ・スミ   |
| 操作（枠ごと）         | キーボード / パッド1〜4 / CPU                 | 最初の枠はキーボード、ほかはCPU    |
| 強さ（CPUの枠ごと）    | おまかせ / よわい / ふつう / つよい           | おまかせ                           |

ルールプリセットを変えると残機・制限時間・ギミックがまとめて切り替わります。いずれかを個別に変更した場合はカスタム表示になります。ステージ側で存在しないギミック（回廊の崩落・風、工場の風）は自動で無効化される仕様です。

枠ごとの行はモードの人数分（一騎打ちと稽古は2行、乱闘は4行）並びます。行の先頭にある枠の形とキャラクター名のボタンを押すと見た目を選べます。ほかの行が使っている操作を選んだ場合は2つの行の操作が入れ替わる仕様で、保存したパッドが未接続の行には「パッド2（未接続）」と表示されます。

タイトル画面ではゲームパッドからも参加できます。未割り当てのパッドで `A` か `Start` を押すと最初のCPU枠に入り、参加中のパッドで `B` を押すとCPUに戻ります（枠1からは抜けられません）。`Y` を押すとその枠の見た目選びが開きます。

試合開始時に未接続のパッドはその試合だけCPUに置き換わります（枠1ならキーボードへフォールバック）。保存した設定と各枠の見た目は変わりません。セット戦・稽古・チュートリアルでは、試合中に参加パッドが切断されると一時停止し、再接続まで再開できません。

### セット戦と対戦結果

一騎打ちでBO3（2勝先取）またはBO5（3勝先取）を選ぶと、HUDに現在のセットスコア（例: `YOU 1勝 – CPU 01 0勝`）が表示されます。引き分けはどちらにも勝ち星を加えず、次の試合へ進みます。セット途中でタイトルへ戻ると未完了のまま終了し、勝ち星は持ち越しになりません。

試合結果画面には選手ごとの戦績（与ダメージ、被ダメージ、KO、被KOの内訳、命中率、回避成功数）が表示されます。セット途中は「この試合」、セット決着後は「セット累計」が初期表示となり、タブで切り替えられます。

### CPUラダー

タイトル画面でCPUラダーを選ぶと、1Pの見た目と操作端末を引き継いで全4戦の勝ち抜き戦に挑めます。通常の対戦設定（残機・ステージ・試合形式・CPU強さ）は書き換えません。

| 試合  | 対戦相手     | 強さ   | ステージ     |
| ----- | ------------ | ------ | ------------ |
| 第1戦 | 庭園の見習い | よわい | 浮遊庭園     |
| 第2戦 | 遺跡の番人   | ふつう | 中央穴の遺跡 |
| 第3戦 | 工場の剣士   | ふつう | コンベア工場 |
| 第4戦 | 天空の王者   | つよい | 細い橋の回廊 |

各戦は標準ルール（残機3・単発）です。敗北または引き分け時は同じ相手から再挑戦でき、結果画面に勝利・敗北・引き分け・再挑戦回数・合計試合時間が表示されます。進行状況はその挑戦中だけ保持されます。

### 稽古モード

稽古では `T` キー、パッドの十字キー上、または画面の「稽古設定」ボタンから設定パネルを開けます。`R` キーまたは十字キー下で、両キャラクターを開始位置と設定ダメージへ即座に戻せます。

- ダミー行動は静止・攻撃を反復（技を指定）・前後に移動・ステップを反復・通常CPUの5種から選べます。前後移動とステップ反復は全ステージで足場を確認しながら動きます。
- 1P・相手それぞれの開始・現在ダメージを0〜999%の範囲で指定できます。スタミナ無限をオンにすると消費後も満タンを保ちます。
- 赤い攻撃判定と緑の体半径を3D上に重ねて表示できます。戦闘状態オーバーレイには現在の状態と残りフレーム、ヒットストップ、取消可否、無敵、空中行動の残数、先行入力（最大6F）と受け身受付（着地前10F）の残りが表示されます。
- 1Pの入力を60Hzで最大10秒（600フレーム）記録し、ダミーに180°反転して再生できます。繰り返し再生をオンにすると、各ループ開始時に両者を初期位置・設定ダメージへ戻して再現します。

### 実戦チュートリアル

タイトル画面の「はじめての方へ · 実戦チュートリアル」から、9つの課題を好きな順で練習できます。

1. 移動・ジャンプ・照準
2. 技の間合いとため
3. 地上回避と空中回避
4. ため・前隙のキャンセル
5. つかみと方向指定投げ
6. %と吹っ飛ばし・KOと残機
7. 場外からの復帰（空中回避＋振り上げ / 突き）
8. 移動するセーフゾーンとエリア外ゲージ
9. 吹き飛ばしからの受け身

課題中はキーボード・ゲームパッド・タッチの切り替えに追従して操作ガイドが更新されます。失敗時は理由を表示し、`R` キーまたはボタンでその課題だけをやり直せます。

### CPUの強さ

対戦CPUは相手の現在位置・向き・接地・表示中の行動だけを一定の観測遅れ（よわい14F / ふつう9F / つよい5F）つきで参照し、人間のボタン入力や先行入力バッファは読みません。

| 強さ   | 動き方                                                                                                                                                                                                                                             |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| よわい | 判断間隔が長く、前隙を見て回避する確率は2割、受け身は2割です。フェイントは使わず、振りかぶり中に向きを直しません。爆撃への反応も遅く、復帰は振り上げのみです。                                                                                     |
| ふつう | 前隙を見て7割、受け身は5割ほど成功します。ためやフェイントを混ぜ、振りかぶり中は半分の速さで向きを直します。復帰に振り上げ・突き・空中回避を使います。                                                                                             |
| つよい | 観測遅れが短く、前隙の回避は9割（同じ技の連打にはさらに反応）、受け身は8割です。ためを見て先に避けてしまうこともあり、キャンセルフェイントに引っかかります。後隙への反撃、空振りキャンセル、ステップ着地点読み、場外・エリア外への投げを使います。 |

## キャラクターと見た目

対戦設定の各行の先頭にあるキャラクターボタン（パッドは `Y`）を押すと、その枠の見た目を選ぶパネルが開きます。人間枠もCPU枠も同じように変更できます。

| 項目       | 選択肢                                                                |
| ---------- | --------------------------------------------------------------------- |
| 動物       | コハク（キツネ） / シロ（ウサギ） / モカ（クマ） / スミ（アライグマ） |
| カラー     | コーラル / スカイ / ラベンダー / マリーゴールド / ミント / ベリー     |
| アクセサリ | なし / ハチマキ / ミニ王冠 / ゴーグル / ベレー帽 / 花かざり           |

- 動物・カラー・アクセサリによる性能差はありません。移動速度、攻撃性能、吹っ飛び、スタミナ、当たり判定に一切影響しません。
- 複数の枠で同じ動物・同じカラーを選んでもそのまま対戦できます。
- パネルを開くと対象キャラクターが拡大表示され、変更が即座に反映されます。上部のタブ（パッドは `LB`・`RB`）で枠を切り替え、「決定」（`Start`）で確定、「キャンセル」（`Esc`・`B`）で元に戻します。
- 同じ見た目でも見分けられるよう、タグ（`YOU` / `P1`〜`P4` / `CPU 01`〜`CPU 03`）と枠ごとの形（▼ 三角、● 丸、■ 四角、★ 星）を頭上ラベル、足元の印、HUDカード、ロックオン表示、結果画面で統一しています。

## 操作

### キーボードとマウス

| 操作                | 入力                   | 補足                                                                       |
| ------------------- | ---------------------- | -------------------------------------------------------------------------- |
| 移動 / DI           | `W` `A` `S` `D`        | 被弾時は吹っ飛び方向の微調整にも使用                                       |
| ロックオン          | `Tab` / マウス中ボタン | 押すたびにオン・オフ。オンの間は狙う相手へ向き続けます。                   |
| 相手切替            | `E` / マウスホイール   | ロックオン中のみ。`E` とホイール下で時計回り、ホイール上で反時計回り       |
| 照準                | マウス / 矢印キー      | ロックオン解除中のみ。矢印キーを優先し、なければカーソルの位置を狙います。 |
| 振り下ろし          | `J` / 左クリック       | 重い一撃。空中の相手に空中で当てるとメテオになります。                     |
| 振り上げ            | `I`                    | 斜め前方へ上昇。対空攻撃と縦の復帰に使用                                   |
| 横振り              | `K` / 右クリック       | 前方の広い扇形を攻撃                                                       |
| 突き                | `L`                    | 前へ踏み込みます。空中では横の復帰に使用                                   |
| ため                | 攻撃を長押し           | 放すと攻撃開始。最大ため後も短時間保持できます。                           |
| キャンセル          | `Q`                    | ため中と振りかぶり中。判定が出てからはキャンセルできません。               |
| ステップ / 受け身   | `Shift` + 移動方向     | 身体の向きを維持。空中は着地まで1回。吹き飛び着地直前に押すと受け身        |
| ジャンプ            | `Space`                | 地上から1回。空中ジャンプなし                                              |
| つかみ              | `U`                    | 地上の近い相手をつかみ、保持中の移動入力方向へ投げます。                   |
| 視点の切り替え      | `V`                    | 自動追随と足場全体の固定視点。画面右上のカメラボタンでも切り替え           |
| 全画面表示の切替    | `F`                    | 対応ブラウザーのみ。右上ボタン・一時停止・設定ダイアログからも切り替え可能 |
| 一時停止 / 再開     | `Esc`                  | 画面右上のボタンからも操作可能                                             |
| 稽古設定 / リセット | `T` / `R`              | 稽古中のみ（`R` はチュートリアルのやり直しにも対応）                       |

ロックオンの状態はプレイヤーごとに独立し、同一セッションの次の試合にも引き継がれます。カメラが斜め見下ろしのため、移動・矢印キー照準・スティック入力は画面基準です。

### ゲームパッド

最大4台まで接続でき、標準ゲームパッド配置を使用します（表記はXbox系）。

| 操作                            | 入力                                    |
| ------------------------------- | --------------------------------------- |
| 移動 / DI                       | 左スティック                            |
| 照準（ロックオン解除中）        | 右スティック                            |
| 横振り / 振り下ろし             | `RB` / `RT`                             |
| 突き / 振り上げ                 | `LB` / `LT`                             |
| ジャンプ / ステップ・受け身     | `A` / `B`                               |
| つかみ / キャンセル             | `X` / `Y`                               |
| ロックオンの切り替え            | `R3`（右スティック押し込み）            |
| 相手切替（ロックオン中）        | 十字キー左右 / 右スティックを左右に弾く |
| 稽古設定 / 稽古リセット         | 十字キー上 / 十字キー下（稽古中のみ）   |
| 視点の切り替え / 一時停止・再開 | `View` / `Start`                        |

タイトル、一時停止、結果画面、各種ダイアログはどのパッドからも操作できます（十字キー・左スティックで移動、`A` で決定、`B` で戻る、`Start` で開始・再開・再戦、音量スライダーは左右で調整）。対応環境では命中・被弾・相殺時にパッドが振動します。

### タッチ・スマートフォン表示

タッチ端末では左のスティックで移動し、右のボタンで攻撃4種・回避・ジャンプ・取消・つかみを操作します。攻撃ボタンは長押しでため、指を離すと攻撃する仕組みです。照準は自動ロックオンとなり、乱闘では「相手切替」ボタンで対象を変えられます。

- スマートフォン縦画面のタイトルは上部38%に3Dアリーナを独立表示し、下部のシートに対戦設定・キャラクター枠・固定の開始ボタンを収めています。残機やギミックなどの詳細ルールは、1行の要約ボタンからボトムシートで開閉できます。
- 対戦中は薄型の選手カードとコンパクトな稽古ピルに切り替え、操作ボタンやノッチ（セーフエリア）と重ならないよう配置します。操作方法・グラフィック設定・全画面切替は一時停止メニューから開けます。
- スティックと攻撃ボタンの連打・同時押しで画面が意図せず拡大されないよう保護しています。操作ガイドや設定ダイアログはピンチ拡大でき、画面が拡大された状態でも2本指のピンチアウトや上部の「元の表示に戻す」バナーから元の倍率へ戻せます。
- 全画面APIに対応したブラウザーでは、タイトル右上・一時停止・設定ダイアログ（PCは `F` キーも可）から全画面表示を切り替えられます。iPhoneのSafariでは「全画面の方法を見る」からホーム画面追加（PWA起動）の手順を表示します。

| 強い光・決着演出を控えめに     | オン / オフ                    | オフ       | オフ     |

| 効果音の音量                   | 0〜100%（5%刻み）              | 80%        | 80%      |

ミュートは画面右上のスピーカーボタンと同期します。「強い光・決着演出を控えめに」をオンにすると、KOや決着時の白いフラッシュと光の柱の芯を抑え、色の縁取りと文字で伝えます。

## 戦闘の特徴

- 振り下ろし・振り上げ・横振り・突きの4種で発生、範囲、踏み込み、吹っ飛びが異なります。着地で後隙は消せません。
- ため中と振りかぶり中（判定が出る前）にキャンセルできます。先払いしたスタミナは戻らず、振りかぶりの遅いキャンセルほど硬直が長くなります。
- ガードはなく、ステップの途中（0.08〜0.20秒）だけ無敵になります。空中でも滞空ごとに1回使え、高さを保ったまま移動できます。
- 硬直明けや着地直前の6フレーム（0.10秒）以内の先行入力を1つ保持し、行動可能になった最初のフレームで実行します（キャンセルは対象外）。
- 吹き飛び中に床へ着地する10フレーム前（約0.17秒）から着地フレームまでに回避を新しく押すと受け身が成立します（最初の8F保護、16F後に再行動、方向入力で12F最大1.8移動）。失敗するとダウン（5F保護、28F後に再行動）になります。
- ため・振りかぶり中は暖かい発光と足元リングで取消可能を示し、判定中だけ白い刃と軌跡を描きます。後隙は暗い刃と割れた足元リング、キャンセルは破片と引き戻し姿勢、回避無敵は墨輪と残像で判別できます。
- 剣の判定同士が交差すると相殺し、双方が反動を受けます。命中時は当事者だけヒットストップが入り、その間の移動入力で水平の吹っ飛び方向を最大±15°曲げられます。
- つかみは地上近距離専用で、0.45秒の保持中に入れた移動方向へ投げます。空振りには0.70秒の後隙があります。
- 残機が残っていれば1.4秒後に上空から復帰し、2.5秒間無敵になります。移動中のセーフゾーンや崩落予告も先読みして安全な床へ降ります。

### ステージと環境ギミック

ステージは4種類あり、当たり判定と3D描画は `src/game/stages.ts` の共通タイル定義から作ります。タイトル画面で切り替えると背景の足場が即座に入れ替わります。

| ステージ                        | 足場                                                                          | 崩落                          | セーフゾーン                         | 風   |
| ------------------------------- | ----------------------------------------------------------------------------- | ----------------------------- | ------------------------------------ | ---- |
| 浮遊庭園（THE FLOATING GARDEN） | 穴のない9×9タイルの正方形                                                     | 2回（5×5タイルまで）          | 予告後に四隅を巡る                   | あり |
| 中央穴の遺跡（SUNKEN RUINS）    | 中央の3×3タイルが穴。まわりを3列の環が囲む                                    | 1回（外周の1列だけ）          | 穴のまわりを周回。穴の真上には来ない | あり |
| 細い橋の回廊（SKY BRIDGES）     | 四方に4×6の島、中央に4×4の広場。広場と各島を幅1.6・長さ3の橋が結ぶ            | なし                          | 広場から橋づたいに4つの島を順に巡る  | なし |
| コンベア工場（CONVEYOR WORKS）  | 穴のない9×9タイル。中央3×3を囲む環状ベルトと、奥・手前の場外レーン（毎秒2.2） | 2回（環状ベルトが外周になる） | 予告後に四隅を巡る                   | なし |

- 移動セーフゾーンは制限時間の30%（最大48秒）から中盤に入り、3秒の予告（破線の到着円と進行矢印）、6秒の等速移動、2秒の待機を繰り返します。制限時間の60%付近で終盤へ移行し、半径を保ったまま各ステージの経路を巡り続けます。
- 安全円の外では毎秒7%のダメージと毎秒1秒分の退場ゲージが溜まり、5秒分で退場します。内側へ戻ると毎秒2秒分ずつ回復します。
- 工場のベルトは地上の全員を同じ速さで運び、空中・一時停止・カウントダウン中は止まります。遺跡の穴や回廊の隙間へ落ちると場外と同じく退場します。
- 標準の制限時間は `150 + 60 × (残機 − 1)` 秒（3機で270秒）、短時間は90秒固定です。時間切れ時は残機が多い選手、同数なら蓄積%が低い選手が勝ちます。

詳しい数値と状態遷移は [戦闘システム設計](docs/combat-design.md) を参照してください。

### モーションとサウンド演出

キャラクターは胴体を順運動学、腕と脚を2ボーンIKで解くローポリリグです。モーションと演出は戦闘状態を読むだけで、当たり判定やフレーム数には影響しません。

- BGMと効果音はすべてWeb Audio APIでリアルタイム合成するため、外部音声ファイルは不要です。タイトル、稽古・チュートリアル、通常戦、終盤クライマックス、結果画面（勝利・敗北・引き分け）の7ループをシーン遷移に合わせてクロスフェードします。効果音は静かな足音・打撃・重要警告の3系統で同時発音数を制御し、乱闘でもため音や爆撃・崩落・KO音が埋もれない設計です。
- 通常の残機喪失、乱闘での脱落、試合決着（単発勝利・セット勝利・ラダークリア・敗北・引き分け）を音・演出・スタンプ・スロー表現で段階的に描き分けます。
