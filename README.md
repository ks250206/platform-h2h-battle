# BRAMBLE

**Little paws. Heavy swords. — 小さな体に、大きな一撃。**

## [ブラウザーでプレイ →](https://ks250206.github.io/platform-h2h-battle/)

インストール不要。GitHub Pagesでそのままプレイできます。

ローポリの動物たちが大剣で戦う、斜め見下ろし視点の3Dプラットフォーム対戦アクションです。ため攻撃を見せて回避を誘い、キャンセルから次の手を選ぶ。蓄積した%が大きい相手ほど遠くへ吹っ飛び、最後まで浮島に残ったプレイヤーが勝ちます。

現在は **1人でCPUと戦うオフラインの試作**です。オンライン対戦、複数人のローカル対戦、キャラクター選択は未実装です。

## ローカルで起動

Node.js **26.13.1**、pnpm **12.21.0**を使用します。Nodeの指定は `.node-version`、pnpmの指定は `package.json` にあります。

```sh
pnpm install
pnpm dev
```

`pnpm install` は `pnpm-workspace.yaml` の `patchedDependencies` に登録した `patches/pixi.js@8.23.0.patch` を自動で適用します。MSAAのサンプル数を設定から指定できるようにするpixi.jsの修正などを含みます。

開発サーバーは `http://localhost:5176` で起動します。WebGL 2に対応したブラウザーで開いてください。音声は「アリーナへ」などの初回操作後に有効になり、画面右上で切り替えられます。

ビルドとプレビュー:

```sh
pnpm build
pnpm preview
```

プレビューは `http://localhost:4176`。生成先は `dist/` で、相対パスを使用した静的サイトとして配信できます。

## モード

| モード          | 内容                                                                                     |
| --------------- | ---------------------------------------------------------------------------------------- |
| 一騎打ち / DUEL | あなたとCPUの1対1。間合い、フェイント、差し返しを試せます。                              |
| 乱闘 / RUMBLE   | あなたと3体のCPUによる4人戦。全員が敵です。                                              |
| 稽古 / PRACTICE | 動かない相手と、ギミックのない足場。落下したキャラクターは復活し、繰り返し練習できます。 |

操作キャラクターはキツネの**コハク**。相手にはウサギの**シロ**、クマの**モカ**、アライグマの**スミ**が登場します。

## 操作

### キーボードとマウス

| 操作            | 入力               | 補足                                                                   |
| --------------- | ------------------ | ---------------------------------------------------------------------- |
| 移動            | `W` `A` `S` `D`    | 被弾時は吹っ飛び方向の微調整にも使用                                   |
| 照準            | マウス / 矢印キー  | 矢印キー入力を優先。マウスを動かすとマウス照準になります。             |
| 自動照準に戻す  | `Tab`              | 最寄りの生存相手を狙います。再びマウスを動かすとマウス照準に戻ります。 |
| 振り下ろし      | `J` / 左クリック   | 重い一撃。空中の相手に空中で当てるとメテオになります。                 |
| 振り上げ        | `I`                | 斜め前方へ上昇。対空攻撃と縦の復帰に使用                               |
| 横振り          | `K` / 右クリック   | 前方の広い扇形を攻撃                                                   |
| 突き            | `L`                | 前へ踏み込みます。空中では横の復帰に使用                               |
| ため            | 攻撃を長押し       | 放すと攻撃開始。最大ため後も短時間保持できます。                       |
| キャンセル      | `Q`                | ため中と振りかぶり中。判定が出てからはキャンセルできません。           |
| ステップ        | `Shift` + 移動方向 | 地上のみ。身体の向きを維持。方向入力がなければ前方へ                   |
| ジャンプ        | `Space`            | 地上から1回。空中ジャンプなし                                          |
| つかみ          | `U`                | 地上の近い相手をつかみ、保持中の移動入力方向に投げます。               |
| 一時停止 / 再開 | `Esc`              | 画面右上のボタンからも操作可能                                         |

ゲーム開始時は自動照準です。ため中の方向転換には速度制限があり、攻撃確定後とステップ中は向きが固定されます。

カメラは足場を斜め上から見下ろしているため、移動と矢印キーの照準は画面基準です。`W` は画面の上方向で、足場の上では斜めに進みます。ゲームパッドの左右スティックとタッチのスティックも同じです。マウス照準はカーソルの位置を狙います。

### ゲームパッド

ブラウザーの標準ゲームパッド配置を使用します。以下のボタン名はXbox系の表記です。

| 操作                                  | 入力                  |
| ------------------------------------- | --------------------- |
| 移動 / DI                             | 左スティック          |
| 照準                                  | 右スティック          |
| 振り下ろし / 横振り / 突き / 振り上げ | `A` / `B` / `X` / `Y` |
| ステップ / ジャンプ                   | `LB` / `RB`           |
| キャンセル / つかみ                   | `LT` / `RT`           |
| 一時停止 / 再開                       | `Start`               |

接続してからボタンを押すと認識されます。ボタンの印字とブラウザーが報告する配置は機種によって異なります。

### タッチ

タッチ端末では左のスティックで移動し、右のボタンで攻撃・回避・ジャンプ・取消・つかみを操作します。攻撃ボタンの長押しでため、指を離すと攻撃します。照準は最寄りの相手を自動で狙います。

## グラフィック設定

画面右上の歯車ボタン、一時停止画面の「グラフィック設定」、タイトル画面の「グラフィック設定」リンクから開きます。変更はその場で反映され、ブラウザーの `localStorage`（キー `bramble.settings.v1`）に保存されます。

初期値は端末によって2通りです。**標準**はGPUで描画しマウスを使う端末、**軽量**はソフトウェア描画（SwiftShaderなど）またはタッチ端末の初期値です。「初期設定に戻す」でその端末の初期値に戻ります。

| 項目                           | 選択肢                         | 標準       | 軽量     |
| ------------------------------ | ------------------------------ | ---------- | -------- |
| 解像度                         | ネイティブ / 短い辺2160〜540px | ネイティブ | 540      |
| 負荷に合わせて解像度を自動調整 | オン / オフ                    | オン       | オン     |
| アンチエイリアス               | なし / MSAA / FXAA / SSAA      | MSAA       | なし     |
| MSAA 倍率                      | 2x / 4x / 8x                   | 4x         | 4x       |
| FPS 上限                       | 制限なし / 30〜240の7段階      | 制限なし   | 制限なし |
| 影の品質                       | なし / 低 / 中 / 高            | 中         | なし     |
| 陰影を強調 (SSAO・重い)        | オン / オフ                    | オフ       | オフ     |
| FPS を表示                     | オン / オフ                    | オフ       | オフ     |
| 画面の揺れ                     | オン / オフ                    | オン       | オン     |

解像度と自動調整は3Dの描画だけに適用し、文字とHUDは画面の解像度のまま描きます。SSAAは縦横2倍で描いて縮小します。MSAAの倍率とSSAOは、端末が対応している場合だけ選べます。影を有効にすると、キャラクターや剣が床に実際の影を落とします。画面の揺れをオフにすると、命中・相殺・爆撃・打ち込みなどで起きるカメラの揺れを止めます。

## 戦闘の特徴

- **4種の大剣攻撃:** 発生・範囲・踏み込み・吹っ飛びが異なります。長い前隙と後隙を持ち、着地で後隙を消すことはできません。
- **キャンセル:** ためを見せてから、通常キャンセルやステップへ移れます。先払いしたスタミナは戻りません。振りかぶり中も判定が出る前ならキャンセルできますが、攻撃のスタミナは戻らず、止めるのが遅いほど硬直が長くなります。
- **ガードなしのステップ防御:** 無敵はステップの一部だけ。身体の向きを保ったまま前後左右に動けます。
- **スタミナ:** 攻撃、ステップ、つかみに使用。歩行とジャンプは消費しません。
- **%と吹っ飛ばし:** ダメージ蓄積に応じて吹っ飛びが強くなります。空中の振り上げと突きはそれぞれ着地まで1回です。
- **剣の相殺:** 攻撃中の剣同士が交差すると、双方が反動を受けます。
- **ヒットストップ:** 命中時に当事者の動きを短く止め、大剣の手応えを出します。
- **DI:** 被弾時の移動入力で水平の吹っ飛び方向を最大15°曲げられます。速度やメテオの上下方向は反転しません。
- **位置を動かすつかみ:** 近距離限定で、空振りには大きな後隙があります。

### 浮遊庭園

通常モードでは、時間とともに外周タイルが崩れ、移動するセーフゾーン、予告付き爆撃、弱い風が発生します。

セーフゾーンの外では%と**エリア外ゲージ**が増えます。ゲージが5秒分に達すると退場。安全地帯に戻ると毎秒2秒分ずつ回復し、即座にはリセットされません。試合は1ライフ制で、150秒経過時には生存者のうち蓄積%が最も低いキャラクターが勝ちます。同率なら引き分けです。稽古には時間制限とギミックがありません。

詳しい数値と状態遷移は [戦闘システム設計](docs/combat-design.md) を参照してください。

### モーション

キャラクターは関節ごとに分かれたローポリのリグで、胴体は順運動学、腕と脚は2ボーンIKで解いています。モーションは見た目だけの処理で、戦闘状態を読むだけで結果には影響しません。

- **構え:** 剣を利き手側の後ろに引き、切っ先を床に付けた構えで待機します。
- **攻撃:** 技ごとに振りかぶり → 斬撃 → 振り抜きのキーポーズを持ち、腰が先に回って剣が遅れてついてきます。地上の振り下ろしは剣を床に打ち込みます。
- **持ち替え:** 横振りと振り上げは剣が体の反対側で終わり、次の一振りは左右反転して逆方向から振ります。
- **足と重心:** 歩行中の足は体重を受けている間は床に固定され、着地では膝で受け止めます。空中の姿勢、吹っ飛び中の回転、尻尾・耳・スカーフの揺れを重ねます。
- **手応え:** ヒットストップ中はポーズも止まります。剣の軌跡は実際の刃の位置から毎フレーム作り直し、床への打ち込みや剣先の擦れで土煙・ひび・火花を出します。
- **効果音:** 技ごとの風切り音、地上の振り下ろしの打ち込み音、攻撃確定時の小さな踏ん張る音、ため中の一定間隔の音を合成します。

## 技術構成

| 用途                     | 使用技術                             |
| ------------------------ | ------------------------------------ |
| 実行・パッケージ管理     | Node.js 26.13.1 / pnpm 12.21.0       |
| 開発・ビルド・テスト基盤 | Vite Plus 1.7.0 / Vite core 8.3.8000 |
| 言語                     | TypeScript 7.0.2                     |
| UI                       | HTML / Tailwind CSS 4.3.5            |
| 描画                     | PixiJS 8.23.0 / `@pixi/3d` 0.1.0     |
| 効果音                   | Web Audio API                        |

PixiJS 3Dは公式の `@pixi/3d` を使用しています。動物、剣、足場、パーティクルはコードで組み立て、音はWeb Audioで合成しています。外部モデル・画像・音声のダウンロードは不要です。

## 開発と検証

```sh
pnpm typecheck
pnpm test
pnpm build
```

`pnpm check` で上記をまとめて実行できます。`pnpm lint` と `pnpm fmt` も用意しています。

ユニットテストはキャンセルとスタミナ、回避方向と無敵時間、攻撃判定、同一攻撃の再命中防止、相殺、ヒットストップ、DI、空中復帰、つかみ、足場縮小、セーフゾーン、爆撃などの戦闘ロジックを扱います。加えて、画面方向から移動方向への変換、グラフィック設定の初期値・保存・不正値の補正、骨格ソルバーとモーション（剣の位置と攻撃範囲の一致、持ち替え、ヒットストップ中の停止、接地した足）、剣の効果音の発生条件を検証します。

ブラウザーテスト:

```sh
pnpm exec playwright install chromium
pnpm test:e2e
```

Playwrightは本番ビルドをGitHub Pagesと同じサブパスで配信し、タイトル・操作ガイド・入力・CPU戦・モバイル画面と、グラフィック設定の反映と再読み込み後の保持を検証します。既存のChromiumを使う場合は `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` に実行ファイルのパスを設定できます。スクリーンショットと失敗時トレースは `test-results/` に生成します。
