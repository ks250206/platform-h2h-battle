# BRAMBLE

**Little paws. Heavy swords. — 小さな体に、大きな一撃。**

## [ブラウザーでプレイ →](https://ks250206.github.io/platform-h2h-battle/)

インストール不要。GitHub Pagesでそのままプレイできます。

ローポリの動物たちが大剣で戦う、斜め見下ろし視点の3Dプラットフォーム対戦アクションです。ため攻撃を見せて回避を誘い、キャンセルから次の手を選ぶ。蓄積した%が大きい相手ほど遠くへ吹っ飛び、落ちるたびに残機を1つ失います。最後まで残機を残したプレイヤーが勝ちます。

現在は **オフラインの試作**です。1台のブラウザーで、キーボード（またはタッチ）の1人とゲームパッド最大4台のプレイヤーが一緒に遊べます。乱闘は最大4人、一騎打ちと稽古は2人で、プレイヤーのいない枠はCPUが戦います。オンライン対戦とキャラクター選択は未実装です。

## ローカルで起動

Node.js **26.13.1**、pnpm **12.21.0**を使用します。Nodeの指定は `.node-version`、pnpmの指定は `package.json` にあります。

```sh
pnpm install
pnpm dev
```

`pnpm install` は `pnpm-workspace.yaml` の `patchedDependencies` に登録した `patches/pixi.js@8.23.0.patch` を自動で適用します。MSAAのサンプル数を設定から指定できるようにするpixi.jsの修正などを含みます。

開発サーバーは `http://localhost:5176` で起動します。WebGL 2に対応したブラウザーで開いてください。音声は「アリーナへ」などの初回操作後に有効になり、画面右上で切り替えられます。

ビルドとプレビュー:

```sh
pnpm build
pnpm preview
```

プレビューは `http://localhost:4176`。生成先は `dist/` で、相対パスを使用した静的サイトとして配信できます。

## モード

| モード          | 内容                                                                                                                                      |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 一騎打ち / DUEL | 1対1。相手はCPUか、もう1人のプレイヤー。間合い、フェイント、差し返しを試せます。                                                          |
| 乱闘 / RUMBLE   | 4人戦。全員が敵です。プレイヤーが入らない枠はCPUが戦います。                                                                              |
| 稽古 / PRACTICE | 動かない相手と、ギミックのない足場。落下したキャラクターは復活し、繰り返し練習できます。2人目のプレイヤーが相手を操作することもできます。 |

キャラクターはキツネの**コハク**、ウサギの**シロ**、クマの**モカ**、アライグマの**スミ**の4種です。初期状態では枠の順にこの4人が並びます（一騎打ちと稽古は2枠）が、どの枠でも好きな動物・カラー・アクセサリを選べます（[キャラクターと見た目](#キャラクターと見た目)）。最初の枠は必ずプレイヤーが操作し、ほかの枠はプレイヤーかCPUを選べます。

## 対戦設定

タイトル画面の「対戦設定」で、ルールと、各枠のキャラクターと、それを誰が操作するかを選べます。選んだ内容（残機、強さ、操作の割り当て `controls`、枠ごとの見た目 `loadouts`）はブラウザーの `localStorage`（キー `bramble.match.v1`）に保存され、次に開いたときも引き継がれます。残機とCPUの強さは一騎打ちと乱闘だけで使い、稽古では表示しません（残機は無制限で、CPUの相手は動きません）。

| 項目                   | 選択肢                                        | 初期値                           |
| ---------------------- | --------------------------------------------- | -------------------------------- |
| 残機                   | 1〜5                                          | 3                                |
| CPU の強さ             | よわい / ふつう / つよい                      | ふつう                           |
| キャラクター（枠ごと） | 動物4種 / カラー6色 / アクセサリ5種と「なし」 | 枠の順にコハク・シロ・モカ・スミ |
| 操作（枠ごと）         | キーボード / パッド1〜4 / CPU                 | 最初の枠はキーボード、ほかはCPU  |
| 強さ（CPUの枠ごと）    | おまかせ / よわい / ふつう / つよい           | おまかせ                         |

枠ごとの行は、選んだモードの枠の数（一騎打ちと稽古は2行、乱闘は4行）だけ並びます。行の先頭は、その枠の形の印とキャラクターの名前のボタンで、押すと見た目を選べます。操作の選択肢はキーボード、接続中のパッド、CPUです。最初の枠の行にはCPUがなく、CPUの行では最初の枠が使っている操作を選べません。保存したパッドが接続されていない行は「パッド2（未接続）」のように表示します。ほかの行が使っている操作を選ぶと、2つの行の操作が入れ替わります。プレイヤーの行には、1人なら `YOU`、複数なら枠の順に `P1`・`P2`… と表示します。CPUの行には強さの選択（稽古では「動かない」）が出ます。

タイトル画面ではパッドから参加できます。どの枠にも入っていないパッドで `A` か `Start` を押すと、最初のCPUの枠に入ります。参加しているパッドで `B` を押すと抜け、その枠はCPUに戻ります（最初の枠からは抜けられません）。`Y` はそのパッドが操作する枠の見た目選びを開きます。参加も退出もしないときの `A`・`Start`・`B` は通常のメニュー操作です。

試合の開始時に、選んだパッドが接続されていなければ、その枠はその試合だけCPUが戦います（保存した設定は変わりません）。最初の枠のパッドがなければその枠はキーボードで操作し、キーボードを使っていた枠がCPUになります。どの場合も、枠の見た目は変わりません。どちらの場合も対戦設定の下に注意を表示します。「はじめから」と「もう一度、勝負」でも開始時に改めて確認します。

稽古では、2人目のプレイヤーが練習相手（2つ目の枠）を操作できます。CPUの練習相手は強さにかかわらず動きません。

「おまかせ」のCPUは「CPU の強さ」に従います。強さごとの動き方は次のとおりです。

| 強さ   | 動き方                                                                                                                                                                                                                    |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| よわい | 考える間が長く、回避は5回に1回ほど。ためもフェイントも使わず、振りかぶったら向きを直しません。スタミナに余裕があるときだけ攻め、爆撃には直前まで気づかず、復帰は振り上げだけです。                                        |
| ふつう | これまでのCPUと同じ動き。7割ほど回避し、ときどきためやフェイントを混ぜ、振りかぶり中は半分の速さで向きを直します。復帰に振り上げ・突き・空中回避を使います。                                                              |
| つよい | 判断が速く、9割ほど回避します。振りかぶりの終わり際まで引きつけ、剣筋から外れる方向へ避けます。振りかぶり中も全速で向きを直し、空振りになる攻撃は止め、後隙の相手へ踏み込み、足場の端やセーフゾーンの外へ向けて投げます。 |

HUDのカードには残り残機を丸印で、CPUの強さを名前の横に表示します。プレイヤーのカードは、プレイヤーが1人なら `YOU`、複数なら `P1`・`P2`…、CPUは `CPU 01`〜`CPU 03` で、タグの先頭に枠の形の印が付きます。3D画面のキャラクターの上にも同じ形と表示を出します（複数のときは各キャラクターの色。CPUは名前と%、同じ名前のキャラクターがいるときは `CPU 02` のようなタグと%）。落ちて復帰を待つあいだは「復帰中」、復帰直後の無敵中は「無敵」と表示します。操作の一覧は、キーボードのプレイヤーがいればキーの行を、パッドのプレイヤーがいれば `PAD` の行を表示します。

## キャラクターと見た目

対戦設定の各行の先頭にあるキャラクターのボタン（パッドは `Y`）を押すと、その枠の見た目を選ぶパネルが開きます。人間の枠もCPUの枠も同じように選べます。

| 項目       | 選択肢                                                                |
| ---------- | --------------------------------------------------------------------- |
| 動物       | コハク（キツネ） / シロ（ウサギ） / モカ（クマ） / スミ（アライグマ） |
| カラー     | コーラル / スカイ / ラベンダー / マリーゴールド / ミント / ベリー     |
| アクセサリ | なし / ハチマキ / ミニ王冠 / ゴーグル / ベレー帽 / 花かざり           |

- **見た目による性能差はありません。** 動物・カラー・アクセサリは、移動、攻撃の速さと威力、吹っ飛び方、スタミナ、当たり判定に一切関わりません。キャラ固有の技もありません。
- **同じ姿を何人でも選べます。** 同じ動物・同じカラー・同じアクセサリが重なっても、ほかの枠の選択が変わったり、対戦を始められなくなったりしません。
- **その場で確認できます。** パネルを開くと、浮島のそのキャラクターが大きく映り、ゆっくり左右を向きます。選ぶたびに姿がすぐ変わります。パネルの上のタブ（パッドは `LB`・`RB`）でほかの枠に移れます。「決定」（パッドは `Start`）で確定、「キャンセル」（`Esc`、パッドは `B`）でパネルを開く前の姿にすべて戻ります。「元に戻す」は開いたまま戻します。
- **操作とは別々です。** 見た目は枠のもので、操作する端末、プレイヤー番号、CPUの強さを変えません。人間とCPUの切り替え、パッドの参加と退出、切断と再接続のあとも、枠の見た目はそのままです。
- **覚えています。** 選んだ姿は再戦でも、タイトルに戻っても、次にブラウザーを開いても同じです。保存された内容が古い（見た目の項目がない）、欠けている、壊れているときは、その枠の初期のキャラクター（枠の順にコハク・シロ・モカ・スミと元の色、アクセサリなし）に項目ごとに戻します。

カラーはスカーフ、チュニック、剣の宝石、足もとの輪、剣の軌跡、HUDのカードの色になります。キツネは毛の色もカラーに合わせて変わります。布のアクセサリ（ハチマキ、ベレー帽、花かざり）はカラーの色で、毛がカラーと同じ色のキツネではクリーム色になります。アクセサリはどれも頭に付け、動物ごとの耳の位置に合わせてあります。頭のまわりの小さな範囲に収まり、腕や剣には何も付かないので、振りかぶりや後隙、ためのリング、ダメージの表示を隠しません。

同じ動物・同じカラーを選んだキャラクターどうしは、色以外の2つの手掛かりで見分けられます。

- **タグ**：プレイヤーが1人なら `YOU`、複数なら `P1`〜`P4`、CPUは `CPU 01`〜`CPU 03`。
- **枠の形**：枠ごとに決まった形（1番から順に ▼ 三角、● 丸、■ 四角、★ 星）。誰が操作しても、どんな姿でも変わりません。

形とタグは、キャラクターの頭上のラベル、プレイヤーの頭上に浮かぶ印、足もとの輪の手前の印、HUDのカード、ロックオンの表示（`P1 LOCK` など）、結果画面の勝者の表示で共通で、落ちて復帰したあとも同じです。同じ名前のキャラクターがいる試合では、画面中央の通知も「`CPU 02 モカ DOWN`」「`P2 モカ WINS`」のようにタグを付けて知らせます。

## 操作

### キーボードとマウス

| 操作            | 入力                   | 補足                                                                           |
| --------------- | ---------------------- | ------------------------------------------------------------------------------ |
| 移動            | `W` `A` `S` `D`        | 被弾時は吹っ飛び方向の微調整にも使用                                           |
| ロックオン      | `Tab` / マウス中ボタン | 押すたびにオン・オフ。オンの間は狙う相手へ向き続けます。                       |
| 相手切替        | `E` / マウスホイール   | ロックオン中のみ。`E` とホイール下で時計回り、ホイール上で反時計回り           |
| 照準            | マウス / 矢印キー      | ロックオン解除中のみ。矢印キー入力を優先し、なければカーソルの位置を狙います。 |
| 振り下ろし      | `J` / 左クリック       | 重い一撃。空中の相手に空中で当てるとメテオになります。                         |
| 振り上げ        | `I`                    | 斜め前方へ上昇。対空攻撃と縦の復帰に使用                                       |
| 横振り          | `K` / 右クリック       | 前方の広い扇形を攻撃                                                           |
| 突き            | `L`                    | 前へ踏み込みます。空中では横の復帰に使用                                       |
| ため            | 攻撃を長押し           | 放すと攻撃開始。最大ため後も短時間保持できます。                               |
| キャンセル      | `Q`                    | ため中と振りかぶり中。判定が出てからはキャンセルできません。                   |
| ステップ        | `Shift` + 移動方向     | 身体の向きを維持。方向入力がなければ前方へ。空中でも着地まで1回                |
| ジャンプ        | `Space`                | 地上から1回。空中ジャンプなし                                                  |
| つかみ          | `U`                    | 地上の近い相手をつかみ、保持中の移動入力方向に投げます。                       |
| 視点の切り替え  | `V`                    | 自動追随と足場全体の固定視点。画面右上のカメラボタンでも切り替え               |
| 一時停止 / 再開 | `Esc`                  | 画面右上のボタンからも操作可能                                                 |

ロックオンのオン・オフと狙う相手は、プレイヤーごとに別々です。ページを開いたときはオンで、切り替えた状態は同じ枠の次の試合にも引き継がれます。狙う相手は試合開始時に最寄りの相手が選ばれ、ほかの相手が近づいても変わりません。狙っている相手が落ちると、残っている最寄りの相手へ移ります。対象は相手のカードに、プレイヤーが1人なら `LOCK`、複数なら狙っている人を `P1 LOCK` のようにその人の色で表示します。3D画面の相手には何も描きません。

ため中と振りかぶり中の方向転換には速度制限があり、振りかぶり中が最も遅くなります。判定が出てからとステップ中は向きが固定されます。

カメラは足場を斜め上から見下ろしているため、移動と矢印キーの照準は画面基準です。`W` は画面の上方向で、足場の上では斜めに進みます。ゲームパッドの左右スティックとタッチのスティックも同じです。マウス照準はカーソルの位置を狙います。

### ゲームパッド

パッドは4台まで、1台につき1人が参加できます（キーボードとマウス、またはタッチは1人分）。ブラウザーの標準ゲームパッド配置を使用します。以下のボタン名はXbox系の表記です。攻撃・回避・ロックオンは『DARK SOULS』、ジャンプは『大乱闘スマッシュブラザーズ』の配置を参考にしています。

| 操作                            | 入力                                    |
| ------------------------------- | --------------------------------------- |
| 移動 / DI                       | 左スティック                            |
| 照準（ロックオン解除中）        | 右スティック                            |
| 横振り / 振り下ろし             | `RB` / `RT`                             |
| 突き / 振り上げ                 | `LB` / `LT`                             |
| ジャンプ / ステップ             | `A` / `B`                               |
| つかみ / キャンセル             | `X` / `Y`                               |
| ロックオンの切り替え            | `R3`（右スティック押し込み）            |
| 相手切替（ロックオン中）        | 十字キー左右 / 右スティックを左右に弾く |
| 視点の切り替え / 一時停止・再開 | `View` / `Start`                        |

攻撃ボタンを押し続けるとため、放すと攻撃します。`LT`・`RT` は半分まで押し込むと押したことになります。スティックには中央付近の入力を無視するデッドゾーンがあります。十字キーでは移動しません。`View` はどのパッドでも視点を切り替えますが、`Start` で一時停止できるのは試合に参加しているパッドだけです。

タイトル、一時停止、結果画面、操作方法とグラフィック設定のダイアログは、どのパッドでも操作できます。十字キーか左スティックで選び、`A` で決定、`B` で戻る（一時停止では再開、ダイアログでは閉じる）、`Start` でタイトルでは開始、一時停止では再開、結果画面では再戦します。

試合中に参加しているパッドの接続が切れると、ゲームは一時停止し、どのパッドかを表示します。つなぎ直してから再開してください。対応するブラウザーとパッドでは、攻撃を受けた・当てた・相殺したときにパッドが震えます。

接続してからボタンを押すと認識されます。ボタンの印字とブラウザーが報告する配置は機種によって異なります。

### タッチ

タッチ端末では左のスティックで移動し、右のボタンで攻撃・回避・ジャンプ・取消・つかみを操作します。攻撃ボタンの長押しでため、指を離すと攻撃します。照準は常に相手へロックオンし、乱闘では「相手切替」ボタンで狙う相手を変えられます。視点は画面右上のカメラボタンで切り替えます。

スマートフォンやタブレットでは、対戦設定の「キーボード」が「タッチ」と表示され、その枠をタッチ操作で遊びます。タッチ操作はその枠がある試合でだけ表示されます。

## グラフィック設定

画面右上の歯車ボタン、一時停止画面の「グラフィック設定」、タイトル画面の「グラフィック設定」リンクから開きます。変更はその場で反映され、ブラウザーの `localStorage`（キー `bramble.settings.v1`）に保存されます。

初期値は端末によって2通りです。**標準**はGPUで描画しマウスを使う端末、**軽量**はソフトウェア描画（SwiftShaderなど）またはタッチ端末の初期値です。「初期設定に戻す」でその端末の初期値に戻ります。

| 項目                           | 選択肢                         | 標準       | 軽量     |
| ------------------------------ | ------------------------------ | ---------- | -------- |
| 解像度                         | ネイティブ / 短い辺2160〜540px | ネイティブ | 540      |
| 負荷に合わせて解像度を自動調整 | オン / オフ                    | オン       | オン     |
| アンチエイリアス               | なし / MSAA / FXAA / SSAA      | MSAA       | なし     |
| MSAA 倍率                      | 2x / 4x / 8x                   | 4x         | 4x       |
| FPS 上限                       | 制限なし / 30〜240の7段階      | 制限なし   | 制限なし |
| 影の品質                       | なし / 低 / 中 / 高            | 中         | なし     |
| 陰影を強調 (SSAO・重い)        | オン / オフ                    | オフ       | オフ     |
| FPS を表示                     | オン / オフ                    | オフ       | オフ     |
| 画面の揺れ                     | オン / オフ                    | オン       | オン     |
| 視点の自動追随                 | オン / オフ                    | オン       | オン     |
| パッドの振動                   | オン / オフ                    | オン       | オン     |

解像度と自動調整は3Dの描画だけに適用し、文字とHUDは画面の解像度のまま描きます。SSAAは縦横2倍で描いて縮小します。MSAAの倍率とSSAOは、端末が対応している場合だけ選べます。影を有効にすると、キャラクターや剣が床に実際の影を落とします。画面の揺れをオフにすると、命中・相殺・爆撃・打ち込みなどで起きるカメラの揺れを止めます。視点の自動追随がオンのときは、足場に残っているキャラクターを画面に収めるようにカメラが動き、近くに集まると寄り、離れると足場全体を映す固定視点へ戻ります。オフでは常に固定視点です。`V` キー、ゲームパッドの `View`、画面右上のカメラボタンでも切り替えられます。パッドの振動（「演出」の欄）をオフにすると、パッドで遊ぶ人の被弾・命中・相殺の振動を止めます。

## 戦闘の特徴

- **4種の大剣攻撃:** 発生・範囲・踏み込み・吹っ飛びが異なります。長い前隙と後隙を持ち、着地で後隙を消すことはできません。
- **キャンセル:** ためを見せてから、通常キャンセルやステップへ移れます。先払いしたスタミナは戻りません。振りかぶり中も判定が出る前ならキャンセルできますが、攻撃のスタミナは戻らず、止めるのが遅いほど硬直が長くなります。
- **ガードなしのステップ防御:** 無敵はステップの一部だけ。身体の向きを保ったまま前後左右に動けます。空中でも着地まで1回だけ使え、ほとんど高さを失わずに地上と同じ距離を進みます。
- **振りかぶり中の向き直し:** 攻撃を確定した後も、判定が出るまではゆっくり照準へ向き直れます。判定が出た剣は向きが固定されます。
- **スタミナ:** 攻撃、ステップ、つかみに使用。歩行とジャンプは消費しません。
- **%と吹っ飛ばし:** ダメージ蓄積に応じて吹っ飛びが強くなります。空中の振り上げ、突き、ステップはそれぞれ着地まで1回です。
- **剣の相殺:** 攻撃中の剣同士が交差すると、双方が反動を受けます。
- **ヒットストップ:** 命中時に当事者の動きを短く止め、大剣の手応えを出します。
- **DI:** 被弾時の移動入力で水平の吹っ飛び方向を最大15°曲げられます。速度やメテオの上下方向は反転しません。
- **位置を動かすつかみ:** 近距離限定で、空振りには大きな後隙があります。
- **残機と復帰:** 落ちても残機が残っていれば、1.4秒後に足場の上空から降りてきます。復帰位置はセーフゾーンの内側（有効になる前は中央付近）で、2.5秒間は点滅して攻撃を受けません。%は0に、スタミナは満タンに戻ります。

### 浮遊庭園

通常モードでは、時間とともに外周タイルが崩れ、移動するセーフゾーン、予告付き爆撃、弱い風が発生します。

セーフゾーンの外では%と**エリア外ゲージ**が増えます。ゲージが5秒分に達すると退場し、残機を1つ失います。安全地帯に戻ると毎秒2秒分ずつ回復し、即座にはリセットされません。制限時間は150秒に、残機が1つ増えるごとに60秒を加えた長さです（初期設定の3機なら270秒）。時間切れでは残機の多いキャラクター、同数なら蓄積%の低いキャラクターが勝ちます。それも同率なら引き分けです。稽古には時間制限とギミックがなく、落ちても何度でも復活します。

詳しい数値と状態遷移は [戦闘システム設計](docs/combat-design.md) を参照してください。

### モーション

キャラクターは関節ごとに分かれたローポリのリグで、胴体は順運動学、腕と脚は2ボーンIKで解いています。モーションは見た目だけの処理で、戦闘状態を読むだけで結果には影響しません。

- **構え:** 剣を利き手側の後ろに引き、切っ先を床に付けた構えで待機します。
- **攻撃:** 技ごとに振りかぶり → 斬撃 → 振り抜きのキーポーズを持ち、腰が先に回って剣が遅れてついてきます。地上の振り下ろしは剣を床に打ち込みます。
- **持ち替え:** 横振りと振り上げは剣が体の反対側で終わり、次の一振りは左右反転して逆方向から振ります。
- **足と重心:** 歩行中の足は体重を受けている間は床に固定され、着地では膝で受け止めます。空中の姿勢、吹っ飛び中の回転、空中回避の宙返り、尻尾・耳・スカーフの揺れを重ねます。復帰直後の無敵中は体が点滅します。
- **手応え:** ヒットストップ中はポーズも止まります。剣の軌跡は実際の刃の位置から毎フレーム作り直し、床への打ち込みや剣先の擦れで土煙・ひび・火花を出します。命中と相殺では火花が飛び散り、静電気のような小さな稲妻と閃光が走ります。
- **効果音:** 技ごとの風切り音、地上の振り下ろしの打ち込み音、攻撃確定時の小さな踏ん張る音、ため中の一定間隔の音を合成します。

## 開発と検証

```sh
pnpm typecheck
pnpm test
pnpm build
```

`pnpm check` で上記をまとめて実行できます。`pnpm lint` と `pnpm fmt` も用意しています。

ユニットテストはキャンセルとスタミナ、回避方向と無敵時間、振りかぶり中の向き直し、空中回避、攻撃判定、同一攻撃の再命中防止、相殺、ヒットストップ、DI、空中復帰、つかみ、足場縮小、セーフゾーン、爆撃などの戦闘ロジックを扱います。残機と復帰（復帰位置、無敵時間、復帰待ちの扱い、勝敗と制限時間）、CPUの強さごとの違い、ロックオンの対象選択と切り替え、対戦設定の保存と不正値の補正も検証します。キャラクターと見た目では、どの枠（人間・CPU）でもどの動物でも選べること、同じ姿が重なってもよいこと、古い保存内容や壊れた内容の補正と初期のキャラクター、見た目の変更が操作・難易度・個別の強さに影響しないこと（参加・退出・未接続のパッドを含む）、同じ入力なら動物・カラー・アクセサリが違っても全フレームで同じ結果になること、タグと枠の形、同じ名前のときの通知、復帰後の見た目、キャラクターのモデルの作り分けとアクセサリの大きさを検証します。ローカル対戦では、プレイヤーの枠と番号の決まり方、プレイヤーごとに独立した入力と押下の保持、スタミナ不足の通知が1人のときだけ出ること、復帰後もプレイヤーのままであること、プレイヤーとCPUが混ざった勝敗、操作の入れ替え・参加・退出と未接続のパッドの扱いを検証します。パッドの割り当て（ボタン、トリガーのしきい値、スティックのデッドゾーン、右スティックの弾き、メニューのリピート、振動の条件）も対象です。加えて、画面方向から移動方向への変換、グラフィック設定の初期値・保存・不正値の補正、骨格ソルバーとモーション（剣の位置と攻撃範囲の一致、持ち替え、ヒットストップ中の停止、接地した足）、剣の効果音の発生条件を検証します。

ブラウザーテスト:

```sh
pnpm exec playwright install chromium
pnpm test:e2e
```

Playwrightは本番ビルドをGitHub Pagesと同じサブパスで配信し、3つのファイルの11のテストで、タイトル・操作ガイド・入力（空中回避を含む）・対戦設定を反映したCPU戦・ロックオンと照準の切り替え・視点の切り替え・落下と復帰・モバイル画面と、グラフィック設定と対戦設定の反映と再読み込み後の保持を検証します。`e2e/multiplayer.spec.ts` は偽のゲームパッドを使い、タイトルでの参加と退出、操作の入れ替え、キーボードとパッドの2人による一騎打ち（`P1`/`P2` の表示、別々の移動と攻撃、`Start` での一時停止と再開、切断時の一時停止）と、パッドだけでの見た目選び（`Y` で開く、十字キーと `A` で選ぶ、`B` で取り消す、`Start` で決定して開始）を確認します。`e2e/character.spec.ts` は、キーボード・マウス・タッチでの見た目選び、その場での反映と取り消し、再読み込み後の保持、古い保存内容の読み込み、同じ姿の4人でもタグと枠の形が別々になることを確認します。既存のChromiumを使う場合は `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` に実行ファイルのパスを設定できます。スクリーンショットと失敗時トレースは `test-results/` に生成します。
