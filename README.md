# BRAMBLE

**Little paws. Heavy swords. — 小さな体に、大きな一撃。**

ローポリの動物たちが大剣で戦う、見下ろし3Dプラットフォーム対戦アクションです。ため攻撃を見せて回避を誘い、キャンセルから次の手を選ぶ。蓄積した%が大きい相手ほど遠くへ吹っ飛び、最後まで浮島に残ったプレイヤーが勝ちます。

現在は **1人でCPUと戦うオフラインの試作**です。オンライン対戦、複数人のローカル対戦、キャラクター選択は未実装です。

## 起動

Node.js **26.13.1**、pnpm **12.21.0**を使用します。Nodeの指定は `.node-version`、pnpmの指定は `package.json` にあります。

```sh
pnpm install
pnpm dev
```

開発サーバーは `http://localhost:5176` で起動します。WebGL 2に対応したブラウザーで開いてください。音声は「アリーナへ」などの初回操作後に有効になり、画面右上で切り替えられます。

ビルドとプレビュー:

```sh
pnpm build
pnpm preview
```

プレビューは `http://localhost:4176`。生成先は `dist/` で、相対パスを使用した静的サイトとして配信できます。

## モード

| モード          | 内容                                                                                     |
| --------------- | ---------------------------------------------------------------------------------------- |
| 一騎打ち / DUEL | あなたとCPUの1対1。間合い、フェイント、差し返しを試せます。                              |
| 乱闘 / RUMBLE   | あなたと3体のCPUによる4人戦。全員が敵です。                                              |
| 稽古 / PRACTICE | 動かない相手と、ギミックのない足場。落下したキャラクターは復活し、繰り返し練習できます。 |

操作キャラクターはキツネの**コハク**。相手にはウサギの**シロ**、クマの**モカ**、アライグマの**スミ**が登場します。

## 操作

### キーボードとマウス

| 操作            | 入力               | 補足                                                                   |
| --------------- | ------------------ | ---------------------------------------------------------------------- |
| 移動            | `W` `A` `S` `D`    | 被弾時は吹っ飛び方向の微調整にも使用                                   |
| 照準            | マウス / 矢印キー  | 矢印キー入力を優先。マウスを動かすとマウス照準になります。             |
| 自動照準に戻す  | `Tab`              | 最寄りの生存相手を狙います。再びマウスを動かすとマウス照準に戻ります。 |
| 振り下ろし      | `J` / 左クリック   | 重い一撃。空中の相手に空中で当てるとメテオになります。                 |
| 振り上げ        | `I`                | 斜め前方へ上昇。対空攻撃と縦の復帰に使用                               |
| 横振り          | `K` / 右クリック   | 前方の広い扇形を攻撃                                                   |
| 突き            | `L`                | 前へ踏み込みます。空中では横の復帰に使用                               |
| ため            | 攻撃を長押し       | 放すと攻撃開始。最大ため後も短時間保持できます。                       |
| ためキャンセル  | `Q`                | ため中のみ。振り始めてからはキャンセルできません。                     |
| ステップ        | `Shift` + 移動方向 | 地上のみ。身体の向きを維持。方向入力がなければ前方へ                   |
| ジャンプ        | `Space`            | 地上から1回。空中ジャンプなし                                          |
| つかみ          | `U`                | 地上の近い相手をつかみ、保持中の移動入力方向に投げます。               |
| 一時停止 / 再開 | `Esc`              | 画面右上のボタンからも操作可能                                         |

ゲーム開始時は自動照準です。ため中の方向転換には速度制限があり、攻撃確定後とステップ中は向きが固定されます。

### ゲームパッド

ブラウザーの標準ゲームパッド配置を使用します。以下のボタン名はXbox系の表記です。

| 操作                                  | 入力                  |
| ------------------------------------- | --------------------- |
| 移動 / DI                             | 左スティック          |
| 照準                                  | 右スティック          |
| 振り下ろし / 横振り / 突き / 振り上げ | `A` / `B` / `X` / `Y` |
| ステップ / ジャンプ                   | `LB` / `RB`           |
| ためキャンセル / つかみ               | `LT` / `RT`           |
| 一時停止 / 再開                       | `Start`               |

接続してからボタンを押すと認識されます。ボタンの印字とブラウザーが報告する配置は機種によって異なります。

### タッチ

タッチ端末では左のスティックで移動し、右のボタンで攻撃・回避・ジャンプ・取消・つかみを操作します。攻撃ボタンの長押しでため、指を離すと攻撃します。照準は最寄りの相手を自動で狙います。

## 戦闘の特徴

- **4種の大剣攻撃:** 発生・範囲・踏み込み・吹っ飛びが異なります。長い前隙と後隙を持ち、着地で後隙を消すことはできません。
- **ためキャンセル:** ためを見せてから、通常キャンセルやステップへ移れます。先払いしたスタミナは戻りません。
- **ガードなしのステップ防御:** 無敵はステップの一部だけ。身体の向きを保ったまま前後左右に動けます。
- **スタミナ:** 攻撃、ステップ、つかみに使用。歩行とジャンプは消費しません。
- **%と吹っ飛ばし:** ダメージ蓄積に応じて吹っ飛びが強くなります。空中の振り上げと突きはそれぞれ着地まで1回です。
- **剣の相殺:** 攻撃中の剣同士が交差すると、双方が反動を受けます。
- **ヒットストップ:** 命中時に当事者の動きを短く止め、大剣の手応えを出します。
- **DI:** 被弾時の移動入力で水平の吹っ飛び方向を最大15°曲げられます。速度やメテオの上下方向は反転しません。
- **位置を動かすつかみ:** 近距離限定で、空振りには大きな後隙があります。

### 浮遊庭園

通常モードでは、時間とともに外周タイルが崩れ、移動するセーフゾーン、予告付き爆撃、弱い風が発生します。

セーフゾーンの外では%と**エリア外ゲージ**が増えます。ゲージが5秒分に達すると退場。安全地帯に戻ると毎秒2秒分ずつ回復し、即座にはリセットされません。試合は1ライフ制で、150秒経過時には生存者のうち蓄積%が最も低いキャラクターが勝ちます。同率なら引き分けです。稽古には時間制限とギミックがありません。

詳しい数値と状態遷移は [戦闘システム設計](docs/combat-design.md) を参照してください。

## 技術構成

| 用途                     | 使用技術                             |
| ------------------------ | ------------------------------------ |
| 実行・パッケージ管理     | Node.js 26.13.1 / pnpm 12.21.0       |
| 開発・ビルド・テスト基盤 | Vite Plus 1.7.0 / Vite core 8.3.8000 |
| 言語                     | TypeScript 7.0.2                     |
| UI                       | HTML / Tailwind CSS 4.3.5            |
| 描画                     | PixiJS 8.23.0 / `@pixi/3d` 0.1.0     |
| 効果音                   | Web Audio API                        |
| ブラウザーテスト         | Playwright                           |

PixiJS 3Dは公式の `@pixi/3d` を使用しています。動物、剣、足場、パーティクルはコードで組み立て、音はWeb Audioで合成しています。外部モデル・画像・音声のダウンロードは不要です。

## 開発と検証

```sh
pnpm typecheck
pnpm test
pnpm build
```

`pnpm check` で上記をまとめて実行できます。`pnpm lint` と `pnpm fmt` も用意しています。

ユニットテストはキャンセルとスタミナ、回避方向と無敵時間、攻撃判定、同一攻撃の再命中防止、相殺、ヒットストップ、DI、空中復帰、つかみ、足場縮小、セーフゾーン、爆撃などを扱います。

ブラウザーテスト:

```sh
pnpm exec playwright install chromium
pnpm test:e2e
```

Playwrightは開発サーバーを起動し、タイトル・操作ガイド・入力・CPU戦・モバイル画面を検証します。既存のChromiumを使う場合は `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` に実行ファイルのパスを設定できます。スクリーンショットと失敗時トレースは `test-results/` に生成します。

### 主なファイル

| 場所                 | 役割                                             |
| -------------------- | ------------------------------------------------ |
| `src/main.ts`        | 起動、ゲームループ、各モジュールの接続           |
| `src/game/types.ts`  | ゲーム状態と入力の型                             |
| `src/game/tuning.ts` | 攻撃、スタミナ、回避、フィールドなどの初期調整値 |
| `src/game/engine.ts` | 60Hz固定更新、状態遷移、CPU、環境、勝敗          |
| `src/game/combat.ts` | 攻撃・相殺判定、DI、足場判定                     |
| `src/game/input.ts`  | キーボード、マウス、ゲームパッド、タッチ         |
| `src/game/audio.ts`  | 効果音の合成と再生                               |
| `src/render/`        | PixiJS 3Dのシーン、モデル、アニメーション        |
| `src/ui/GameUI.ts`   | メニュー、HUD、結果、操作ガイド                  |
| `tests/` / `e2e/`    | 戦闘ロジック / ブラウザーの検証                  |

ゲーム状態は描画から独立しています。バランス調整はまず `ATTACKS` と `RULES` から行い、具体的な読み合いを稽古と一騎打ちで確認する構成です。
