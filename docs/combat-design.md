# 戦闘システム設計

この文書はBRAMBLEの試作に実装したルールを説明します。数値はバランス調整の出発点です。定数の中心は [`src/game/tuning.ts`](../src/game/tuning.ts)、状態遷移と試合処理は [`src/game/engine.ts`](../src/game/engine.ts) にあります。

## 1. 戦闘の狙い

大剣の長い前隙・後隙に、ためキャンセルと方向を保つステップを組み合わせています。相手のためを見てすぐ回避すればフェイントに捕まり、攻撃を確定させれば空振りを狙われる、という読み合いが中心です。

ガードはありません。通常移動で間合いを外す、短い無敵を合わせる、空中へ逃げる、先に攻撃を当てる、という選択肢を使います。つかみは、相手を危険な位置へ動かす役割です。

## 2. 状態とキャンセル

攻撃の基本経路は `idle → charge → windup → active → recovery → idle` です。

| 状態                   | できること・制約                                                   |
| ---------------------- | ------------------------------------------------------------------ |
| `idle` / 待機          | 移動、照準、攻撃開始、地上ジャンプ、地上ステップ、地上つかみ       |
| `charge` / ため        | 低速移動、制限付き旋回、通常キャンセル、地上ステップへのキャンセル |
| `windup` / 前隙        | 攻撃確定後。照準と技が固定され、キャンセル不可                     |
| `active` / 判定中      | 剣の当たり判定が有効。各技の踏み込みや上昇が発生                   |
| `recovery` / 後隙      | 攻撃・回避・ジャンプへキャンセル不可。空中のみ弱い移動入力が可能   |
| `cancel` / 取消硬直    | 0.12秒後に待機へ戻る                                               |
| `step` / ステップ      | 移動方向と身体の向きを固定。指定した区間だけ無敵                   |
| `hitstun` / 被弾硬直   | 吹っ飛び中。ヒットストップ終了時にDIを反映                         |
| `clash` / 相殺         | 0.28秒の反動硬直                                                   |
| `grab` / つかみ試行    | 狭い前方判定。失敗時は0.70秒の後隙                                 |
| `throw` / 投げ準備     | 短時間保持し、移動入力で投げる方向を選ぶ                           |
| `grabbed` / つかまれ中 | 相手の前方に拘束。投げ、相手の被弾・退場などで解除                 |
| `dead` / 退場          | 通常モードでは復活しない                                           |

着地しても攻撃の後隙は解除しません。攻撃後隙をジャンプやステップで上書きすることもできません。

### ためとフェイント

- 攻撃ボタンを押すと、スタミナを**10先払い**してために入ります。開始時にはその技の総消費量を持っている必要があります。
- 0.90秒で最大ため。ボタンを放すか、保持が1.30秒に達すると攻撃を確定します。
- 確定時に残りのスタミナを支払い、技固有の前隙を最初から開始します。ため時間で前隙が短くなることはありません。
- `Q` のキャンセルは追加消費なしですが、先払いした10は返却しません。取消硬直は0.12秒です。
- ためからステップに移る場合は、追加で25消費します。先払いを含めた総消費は35。ステップ開始前に0.10秒の無防備な遅延があります。
- ため中の旋回速度は毎秒3.6rad、待機中は毎秒20rad。攻撃確定後は向きを固定します。

スタミナ回復待ち時間は、キャンセルでも再設定します。フェイントを繰り返して無料で安全を確保することはできません。

## 3. 4つの攻撃

以下は無ため時の値です。時間の単位は秒、ダメージは蓄積%への加算値です。

| 技         | 前隙 | 判定持続 | 後隙 | 総スタミナ | ダメージ | 主な役割                                             |
| ---------- | ---: | -------: | ---: | ---------: | -------: | ---------------------------------------------------- |
| 振り下ろし | 0.43 |     0.14 | 0.60 |         25 |       18 | 狭めの前方へ重い一撃。空中ではメテオを狙う           |
| 振り上げ   | 0.38 |     0.22 | 0.62 |         25 |       12 | 対空、斜め前方への上昇、縦の復帰                     |
| 横振り     | 0.35 |     0.18 | 0.48 |         20 |       11 | 前方の扇形。踏み込まず、横への回避を狩る             |
| 突き       | 0.28 |     0.16 | 0.52 |         20 |       10 | 狭い幅と長い前方リーチ。踏み込み、差し返し、横の復帰 |

ため量を0〜1で表すと、ダメージ倍率は `1 + ため量 × 0.65`、吹っ飛び倍率は `1 + ため量 × 0.25` です。最大ためではそれぞれ1.65倍・1.25倍になります。

吹っ飛びは、技の基礎値と**命中後の蓄積%**から求めます。振り下ろしのメテオは、攻撃側・被攻撃側がともに空中の場合に発生し、上下方向の速度を下向きにします。

### 判定

身体は動物の耳や尻尾に左右されない共通の簡略判定です。剣は技ごとの前方距離・横幅・高度差で判定し、横振りは扇形として扱います。

攻撃確定ごとに命中済みの相手を記録し、**同じ一振りは同じ相手に1回だけ命中**します。乱闘では1回の横振りが複数の相手に当たることがあります。

## 4. スタミナとステップ

| 項目             | 初期値 |
| ---------------- | -----: |
| 最大スタミナ     |    100 |
| 消費後の回復待ち | 0.50秒 |
| 回復速度         | 毎秒30 |
| 通常ステップ     |     25 |
| つかみ           |     18 |
| 歩行・ジャンプ   |      0 |

スタミナは待機中・被弾硬直中に回復します。ため、攻撃、後隙、ステップの最中は回復しません。ヒットストップ中は当事者の回復処理も停止します。

不足している行動は開始できませんが、歩行と地上ジャンプは残ります。スタミナを使い切ると、攻撃後に回避する余力がなくなります。

ステップは地上専用で、通常の全体時間は0.30秒です。

| 開始からの時間 | 状態             |
| -------------- | ---------------- |
| 0.00〜0.08秒   | 無敵なし         |
| 0.08〜0.20秒   | 攻撃に対して無敵 |
| 0.20〜0.30秒   | 無敵なし         |

入力方向へ移動しながら身体の向きを維持します。方向入力がなければ前方へ進みます。ためからのステップには、この時間配分の前に0.10秒の遅延が入ります。エリア外ゲージとエリア外ダメージはステップで回避できません。

## 5. ジャンプと復帰

地上の待機状態から1回ジャンプできます。空中ジャンプはありません。

空中の**振り上げと突きは、それぞれ1回**使用できます。使用権は攻撃確定時に消費し、床の上へ正規に着地したときだけ回復します。空中で被弾しても、ためを再入力しても回復しません。ため中のキャンセルでは、空中使用権を消費しません。

地上からの振り上げも上昇に使用するため、その滞空中の振り上げは使用済みです。地上の突きで足場の外へ出た場合も、その滞空中の突きを使用済みとして扱います。

復帰にスタミナも必要です。空中の振り上げは上昇、突きは水平移動と落下速度の緩和を担い、使う順番と向きを選べます。床の下から側面に触れるだけでは着地扱いにしません。

## 6. 相殺・ヒットストップ・DI

### 相殺

同時に攻撃中の剣の判定同士が接触すると相殺します。通常の被弾処理より先に全組み合わせを調べ、相殺した攻撃の通常ダメージを止めます。

相殺した双方には0.11秒のヒットストップ、0.28秒の反動硬直、後方への小さな押し戻しが入ります。単に近くで同時に攻撃しているだけでは相殺しません。横振りは複数の剣線分で近似しています。

相殺しない攻撃の命中候補も一度集めてから適用し、同時命中の打ち合いを残します。乱闘の同時攻撃は安定したID順で処理します。

### ヒットストップと時計

通常命中のヒットストップは0.085秒で、最大ためでは0.110秒になります。停止するのは当事者のモーション、状態時間、物理移動、スタミナ処理です。乱闘のほかの参加者は動き続けます。

**試合時計、足場縮小、爆撃、エリア外ダメージと5秒ゲージは進み続けます。** ヒットストップを利用してエリア外の退場を先送りにはできません。一方、ゲームの一時停止では試合全体の時間が止まります。

### DI

被弾で決まった吹っ飛びは、ヒットストップ終了時の移動入力を使って確定します。水平の角度だけを最大±15°変更し、水平速度の大きさと上下速度は保持します。

純粋な上下方向への吹っ飛びに、DIで新しい水平速度を加えることはありません。メテオを上向きに変えることもできません。

## 7. つかみと投げ

つかみは地上専用。発生0.20秒、判定持続0.09秒、射程1.25で、正面の狭い範囲にだけ当たります。空振りすると0.70秒の後隙があります。

成功後は0.45秒保持し、その間の移動入力で投げ方向を選べます。方向入力がなければ前方へ投げます。投げのダメージは6、投げた側の後隙は0.40秒です。

投げの目的は位置の変更です。セーフゾーン外や崩壊する外周へ向けて使えます。つかんだ側が被弾・退場するなどして行動を継続できなくなった場合、拘束を解除します。

## 8. 足場と環境

通常モードは9×9枚のタイルを敷いた正方形の足場から始まります。1タイルは2ワールド単位、初期の足場は18×18です。

| 仕組み           | 初期仕様                                                         |
| ---------------- | ---------------------------------------------------------------- |
| 外周崩壊         | 32秒で開始。その後22秒ごとに外周1列を除去。4秒前に予告           |
| 最小の足場       | 3×3タイル。足場の半幅3で縮小停止                                 |
| セーフゾーン     | 18秒から有効。縮みながらゆっくり移動し、残った足場の内側に収める |
| エリア外         | 毎秒7%と、毎秒1秒分の退場ゲージを加算                            |
| 安全地帯へ再侵入 | 毎秒2秒分の退場ゲージを回復。蓄積%は減らさない                   |
| 強制退場         | 退場ゲージが5秒分に達したとき                                    |
| 爆撃             | 14秒から11秒間隔。2.1秒の予告後に爆発                            |
| 爆撃数           | 一騎打ちは2か所、乱闘は3か所                                     |
| 爆撃の威力       | 10%と小さな吹っ飛び。短い無敵や十分な高度で回避可能              |
| 風               | 24秒以降の一部時間帯に地上のキャラクターを弱く押す               |

エリア外のルールは**瞬間的な再侵入でリセットする連続5秒タイマーではなく、戻ると徐々に回復するゲージ**です。HUDに現在値を表示します。稽古ではこれらの環境ギミックを無効にします。

## 9. 試合とCPU

通常モードは1ライフ制です。床の下へ大きく落下する、外側へ大きく飛び出す、エリア外ゲージが5秒に達する、のいずれかで退場します。生存者が1人なら勝利、全員同時に退場した場合は引き分けです。

150秒で時間切れとなり、生存者のうち蓄積%が最も少ないキャラクターを勝者にします。最少値が同率（実装上の差が0.01未満）なら引き分けです。

CPUは相手との距離、技の状態、足場の端、セーフゾーン、爆撃を見て行動します。ため、ステップ、つかみ、空中復帰も使います。行動の選択には固定シードの乱数を使います。稽古の相手は操作せず、退場したキャラクターは1.5秒後に復活します。

## 10. 実装と検証の境界

シミュレーションは1/60秒の固定更新です。描画と入力は別モジュールに分け、描画フレーム間の短いボタン入力も次のシミュレーション更新まで保持します。WebGL、モーション、効果音は戦闘結果の計算を担当しません。

カメラは足場を斜めに見下ろす固定の透視カメラです。キー、タッチのスティック、ゲームパッドのスティック、矢印キーの照準は画面上の方向として受け取り、入力モジュールが [`src/game/coordinates.ts`](../src/game/coordinates.ts) のカメラの向きを使って地面上の方向に変換してから、シミュレーションへ渡します。DIの移動入力も同じ変換を通ります。マウス照準はカーソル位置を地面上の点に変換して狙います。シミュレーションが扱うのは常にワールド座標の方向で、この文書の角度や距離はすべてワールド座標の値です。

表示側の処理は、シミュレーションの状態を読んで作るだけで、何も書き戻しません。関節付きのリグとアニメーション（[`src/render/motion.ts`](../src/render/motion.ts)）は、各キャラクターの状態、技、状態時間、ため量、速度から毎フレームのポーズを決め、ヒットストップ中はシミュレーションと同じくポーズを止めます。剣の軌跡、床の土煙・ひび・火花、カメラの揺れ、剣の効果音（風切り、打ち込み、攻撃確定、ため）も同じ状態や状態の変化から作ります。描画上の剣の位置は判定を決めません。判定は第3節の技ごとの範囲で計算し、モーションはその範囲に合わせて作っています。グラフィック設定（解像度、アンチエイリアス、影、FPS上限、画面の揺れなど）は描画だけを変え、1/60秒の更新間隔、数値、判定は変わりません。

ユニットテストでは、状態遷移、消費、無敵区間、同一攻撃の再命中防止、相殺の処理順、DI、空中復帰の回数、拘束解除、フィールド縮小、エリア外ゲージ、爆撃などを検証します。表示側も、画面方向から地面上の方向への変換、描画上の剣が各技の判定範囲を通ること、ヒットストップ中のポーズの停止、剣の効果音の発生条件、グラフィック設定の保存と補正をユニットテストで確認します。PlaywrightのE2Eでは、実際の起動、操作、HUD、CPU戦、タッチ画面、グラフィック設定の反映と保持を確認する構成です。

調整するときは、まず一騎打ち・稽古で「避けた後に反撃が間に合うか」「ためキャンセルで回避を誘えるか」「攻撃と回避の連打がスタミナで抑えられるか」を確認します。乱闘と環境ギミックが加わったときに、位置取りの判断が残るかを続けて見ます。
